# Windows Administration Lab

## Overview

The **Windows Administration Lab** is a hands-on repository that documents my journey of learning and implementing Windows administration in a virtual enterprise environment.

This repository combines conceptual learning, practical implementation, and detailed documentation for every topic covered throughout the lab. Each module includes step-by-step configuration guides, screenshots, verification steps, troubleshooting notes, and hands-on exercises.

The goal of this repository is to build a strong foundation in Windows Administration while creating a structured knowledge base that can also help students, IT professionals, and SOC Analyst learners build and understand a Windows enterprise lab from scratch.

---

# What I Learned

Throughout this lab, I learned how to:

- Build a virtual enterprise lab using Oracle VirtualBox.
- Install and configure Windows Server and Windows 11.
- Configure VirtualBox networking.
- Deploy and manage Active Directory Domain Services (AD DS).
- Configure DNS and DHCP services.
- Manage Organizational Units (OUs), users, and groups.
- Configure Group Policy Objects (GPOs).
- Create and manage shared folders.
- Configure NTFS permissions.
- Perform Windows administration using PowerShell.
- Monitor and troubleshoot Windows systems using Event Viewer.
- Document every configuration step using Markdown and GitHub.

# Repository Organization

Each module in this repository follows a consistent documentation structure:

- Concept Overview
- Architecture (where applicable)
- Step-by-Step Configuration

This structure makes it easier to understand both the theory and the practical implementation of each topic.
