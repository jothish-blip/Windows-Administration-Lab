## Question Tiering Structure

Every topic is broken into three structured levels:

1. **Basic:** Evaluates core definitions, foundational concepts, and architectural principles.
2. **Intermediate:** Tests operational workflows, configuration mechanics, and administrative trade-offs.
3. **Scenario-Based:** Real-world troubleshooting challenges, security investigations, and SOC triage incidents simulating actual on-the-job problems.
